Este repositorio está destinado a recopilar y organizar las prácticas, ejercicios y proyectos desarrollados durante la asignatura de Computación Gráfica. Incluye implementaciones realizadas principalmente con C++ y OpenGL, abordando conceptos como dibujo de primitivas, transformaciones geométricas, manejo de vértices, color, shaders, representación de objetos en 2D y 3D,etc.

Su propósito es documentar el aprendizaje y la aplicación práctica de los fundamentos de la computación gráfica a lo largo del curso.
